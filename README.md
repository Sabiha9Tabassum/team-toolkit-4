# team-toolkit-4
Team Toolkit - Git and GitHub Team(04) Assignment


## Project Overview
Team Toolkit is a simple Python-based command-line application that provides useful tools through different features.

## Features

1. **Calculator:** Performs addition, subtraction, multiplication, and division.
2. **Unit Converter:** Converts distance, weight, and temperature units.
3. **GPA Calculator:** Calculates GPA based on grade points and course credits.
4. **Quiz:** Provides multiple-choice questions and calculates the user's score.
5. **Input Validation:** Checks user inputs and handles invalid entries.

## Requirements
- Python 3.x
- Visual Studio Code or another Python editor

## How to Run

Open the project folder in VS Code and run the individual feature files from the terminal.

Example:

```bash
python src/calculator.py
```

You can replace `calculator.py` with another feature filename to run that feature.
